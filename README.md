# Beauty Maybe Brand Studio

Central independente de planejamento estratégico e identidade visual. Abra `index.html` em um navegador com JavaScript habilitado. A página também tem conteúdo estático para leitura quando o JavaScript não é executado.

16 abas, simulador Instagram/TikTok, capas, legendas, avaliações e exportação JSON. Dados locais do navegador; não publica nas redes sociais.

Branches: `main` (base), `codex/beauty-maybe-brand-studio` (desenvolvimento), `gh-pages` (preparação para publicação). Não habilite Pages público sem autorização: repositório privado não implica site privado. Para acesso privado, use o download autenticado ou hospedagem com autenticação real.
